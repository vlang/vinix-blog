# Vinix blog

Posts for the [Vinix](https://github.com/vlang/vinix) blog at
[blog.vinix-os.org](https://blog.vinix-os.org), served by [Veery](https://veery.blog).

Each post is one Markdown file in the repository root named `YYYY-MM-DD Title.md`. The date is the
publication date and the rest of the name is the title, so the post itself should not start
with a `#` heading repeating it. A Russian translation goes in
`YYYY-MM-DD Заголовок.ru.md` with the same date.

Put images in `images/` and reference them with relative paths, e.g.
`![Docker on Vinix](images/docker-vinix-terminal.png)`. They render on GitHub as they are, and
the blog serves them from its own domain.

New and changed posts appear on the blog after it re-imports this repository.
